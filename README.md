# Restaurant Menu UI/UX Design
A restaurant menu UI/UX design created using Figma that allows users to explore food items, view prices, and place food orders through a user-friendly interface.

## Key Features
- Browse restaurant food items
- Explore menu categories
- View food details and prices
- Select food items to order
- Place food orders
